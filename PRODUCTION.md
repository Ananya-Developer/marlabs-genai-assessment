# First production changes (under 400 words)

Deploy the public Java API and Python workers as separate containers in a private managed container platform. Replace synchronous batches with durable jobs, an encrypted object store for uploads, and a database for job state, immutable policy versions and audit records. A queue provides backpressure and worker scaling. At 10,000 requests/day, peak arrival rate and document size matter more than the daily average. Start with measured capacity and latency targets, not an assumed worker count.

Replace the exercise caller header with verified identity tokens. Resolve tenant and roles server-side, enforce tenant isolation in storage and retrieval, and authenticate service-to-service calls. Minimize personal information sent to any model; require provider retention and residency guarantees. Encrypt transport and stored data, use managed secrets, define retention/deletion rules, and restrict audit access. Scan uploads and parse PDFs in isolated, resource-limited workers. Treat model and document content as untrusted; preserve application-owned access decisions, citations and human review.

The slow approval system should sit behind an adapter with bounded deadlines, concurrency limits and a circuit breaker. Learn its semantics before adding retries: write operations need idempotency keys and reconciliation to prevent duplicate approvals or payments. Queue human review when the integration is unavailable or a policy conflicts. Never turn a triage result into automatic payment authorization.

Track queue depth, processing latency, failure rates, dependency latency, policy version, and evidence selected. Use correlation IDs, sanitized logs and access-controlled audits; avoid logging raw employee documents. Add alerting, dead-letter handling, safe replay, backups, and a tested recovery process. Keep model errors separate from policy outcomes and test tenant isolation adversarially.

Before committing to a delivery date, clarify peak traffic, document sizes/formats, supported languages, latency targets, retention and jurisdiction requirements, SSO/role sources, policy ownership and conflict-resolution rules, approval API authentication and rate limits, sandbox availability, idempotency guarantees, integration error semantics, and the manual escalation owner. Define acceptance criteria and run a small integration spike against the approval system to uncover undocumented behavior.
